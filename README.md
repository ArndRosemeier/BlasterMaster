# Blaster Master

TypeScript + Phaser 3 + Vite revive of Blaster Master (web app for Cursor).

## Open in Cursor

1. Open the folder (on Windows later: `C:\Projekte\BlasterMaster`).
2. Install and run:

```bash
npm install
npm run dev
```

3. Verify before considering work done:

```bash
npm run typecheck && npm run lint && npm run test
```

See `AGENTS.md` for agent conventions and `docs/ARCHITECTURE.md` for layout.
