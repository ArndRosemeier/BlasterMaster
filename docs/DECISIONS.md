# Decision ledger

**Append-only.** One row per decision: the owner's words where there were any, the evidence,
what landed, and what is still unproven. A landing never edits another landing's row.

Docs that restate behaviour rot; docs that record decisions do not. So the behaviour lives in
a test (the test *is* the statement) and the row holds the pointer and the reason.
